# Fundamentals

## Overview

Terraform Fundamentals cover the core concepts required to understand Infrastructure as Code (IaC), Terraform architecture, infrastructure automation, and cloud provisioning.

These concepts form the foundation for all Terraform workflows and production infrastructure management.
