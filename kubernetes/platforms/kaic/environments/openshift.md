# KAIC OpenShift Environment

## Overview

OpenShift Container Platform (OCP) is one of the environment types supported by KAIC.

The recorded session demonstrates KAIC creating a complete OpenShift environment rather than creating only an individual resource.

The demonstrated environment consists of multiple virtual machines configured as an OpenShift cluster.

## OCP Creation

The recorded session describes `kaic create` as supporting:

```text
kaic create
    |
    +-- container
    +-- VM
    +-- OCP
