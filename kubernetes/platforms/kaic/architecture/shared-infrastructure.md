# KAIC Shared Infrastructure

## Overview

KAIC is designed to operate on shared infrastructure used by multiple engineering teams.

The shared-infrastructure model allows teams to consume available compute and hardware resources through a common platform rather than requiring dedicated infrastructure for every workload.
