# KAIC Telemetry

## Overview

KAIC has telemetry configured to provide visibility into environment creation and other operations.

The recorded session explains that telemetry can help the KAIC team identify where an operation is failing.

## Purpose

The primary purpose described in the session is to provide the KAIC team with information about failures and operational problems.

Instead of waiting for every problem to be reported through a user ticket, telemetry can allow the team to identify failures proactively.
