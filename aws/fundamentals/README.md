# Fundamentals

## Overview

AWS Fundamentals introduces the core concepts required to understand how AWS environments are structured, secured, and operated.

These topics provide the foundation for learning AWS networking, storage, databases, security, monitoring, and compute services.

---

## Why Fundamentals Matter

Before learning AWS services, it is important to understand:

- AWS Global Infrastructure
- AWS Accounts
- Shared Responsibility Model
- Identity And Access Management (IAM)
- EC2 Basics

These concepts appear throughout AWS architectures and operational workflows.
