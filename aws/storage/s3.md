

# S3

## Overview

Amazon Simple Storage Service (S3) is AWS's highly scalable object storage service.

S3 is designed to store and retrieve virtually unlimited amounts of data from anywhere while providing high durability, availability, security, and scalability.

It is one of the most widely used AWS services.

---

## Why S3 Matters

Without Object Storage:

```text
Files
  ↓
Local Storage
  ↓
Scaling Challenges
```

With S3:

```text
Files
  ↓
S3 Bucket
  ↓
Durable Storage
```

Benefits:

- Massive Scalability
- High Durability
- Global Accessibility
- Cost Efficiency
- Managed Service

---

## How S3 Works

```text
Application
      ↓
S3 Bucket
      ↓
Objects
```

Data is stored as objects inside buckets.

---

## Core Components

### Bucket

A bucket is a container for storing objects.

Examples:

- Application Files
- Images
- Videos
- Backups

---

### Object

An object consists of:

- Data
- Metadata
- Unique Key

```text
Bucket
  ↓
Object
```

---

### Object Key

A unique identifier for an object within a bucket.

---

## Key Characteristics

### High Durability

S3 is designed for extremely high data durability.

---

### High Availability

Data is replicated across multiple facilities within an AWS Region.

---

### Unlimited Scale

Storage grows automatically without capacity planning.

## S3 vs EBS vs EFS

| Feature | S3 | EBS | EFS |
|----------|----|-----|-----|
| Storage Type | Object | Block | File |
| Scale | Virtually Unlimited | Volume Based | Automatic |
| Shared Access | Yes | Limited | Yes |
| Common Usage | Files, Backups | Databases | Shared Storage |
| Managed Infrastructure | Yes | Yes | Yes |
