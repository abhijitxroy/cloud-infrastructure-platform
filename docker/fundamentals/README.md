# Fundamentals

## Overview

Docker fundamentals provide the core concepts required to understand container platforms, application packaging, container execution, and cloud-native infrastructure.

These concepts form the foundation for learning Docker images, containers, Dockerfiles, networking, storage, operations, and Kubernetes.
