# Containers

## Overview

Containers are lightweight, isolated runtime environments used to execute applications and their dependencies consistently across different environments.

Containers package application code, libraries, runtime components, and configuration into a portable execution unit.

Containers are a foundational technology behind modern cloud-native platforms, Kubernetes environments, DevOps workflows, and platform engineering systems.
