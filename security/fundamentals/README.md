# Fundamentals

## Overview

Security Fundamentals provide the foundational concepts required to protect systems, applications, infrastructure, data, and operational environments.

These concepts form the basis of cloud security, Kubernetes security, platform engineering, DevSecOps, and enterprise security practices.

Understanding security fundamentals is essential before learning IAM, encryption, secrets management, network security, and compliance.
