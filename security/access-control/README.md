# Access Control

## Overview

Access Control determines who can access systems, applications, infrastructure resources, and data, and what actions they are allowed to perform.

It is a foundational security capability used to protect cloud platforms, Kubernetes environments, enterprise applications, and operational systems.

Access control helps organizations reduce security risks while ensuring users and services have appropriate permissions.

---

## Why Access Control Matters

Without Access Control:

```text
Users
   ↓
Unrestricted Permissions
   ↓
Security Risks
```

With Access Control:

```text
Users
   ↓
Identity Verification
   ↓
Permission Evaluation
   ↓
Authorized Access
```

Benefits:

- Infrastructure Protection
- Reduced Security Risk
- Better Governance
- Regulatory Compliance
- Controlled Resource Access
