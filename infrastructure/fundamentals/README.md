# Fundamentals

## Overview

Infrastructure fundamentals provide the core concepts required to understand how modern platforms, cloud environments, distributed systems, and production applications operate.

These concepts form the foundation for learning reliability, resilience, scalability, high availability, capacity planning, cloud infrastructure, Kubernetes, and platform engineering.
